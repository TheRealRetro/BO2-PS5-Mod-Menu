## Build tools

Not included here; both are public:

- [ps5-payload-sdk](https://github.com/ps5-payload-dev/sdk): compiler, linker and
  system library stubs for the payload and the installer.
- `ps5-native-tool` from [ps5-native-app-boilerplate](https://github.com/blackbearreloaded/ps5-native-app-boilerplate):
  converts the linked installer into a PS5 executable and signs it.

See [installer/BUILD.md](installer/BUILD.md) for the build steps.

Black Ops II game files are not part of this project and are not distributed.
